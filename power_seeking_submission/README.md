# Power Seeking EMNLP Submission Snapshot

This folder is a self-contained package of the submission-ready JudgeBench materials.

## Included
- `judgebench.py` — canonical runner copied from `judgebench_V3_final.py`
- `requirements.txt`
- `data/prompts/` — pinned prompt set
- `results/figures/`, `results/stats/`, `results/summaries/` — curated publication outputs
- `results/raw/` — raw `orkspace` outputs, logs, and checkpoints
- `LICENSE` and `CITATION.cff`

## Notes
- The branch containing this folder is `emnlp-unified-submission`.
- The older `orkspace/` tree in the repo root remains as an archive / working copy.
- For the clean submission snapshot, use this folder rather than the mixed root workspace.
