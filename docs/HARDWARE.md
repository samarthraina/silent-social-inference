# Hardware

The study was designed to run on a single high-memory GPU for the full
behavioral and mechanistic pipeline.

## Practical baseline

- Behavioral runs: a single 48-80 GB GPU is sufficient.
- Mechanistic patching: a single 80 GB GPU is recommended.
- Figure regeneration and summary-table work: CPU-only is enough.

For the latest run-time assumptions and model-specific notes, check the root
`README.md`.
